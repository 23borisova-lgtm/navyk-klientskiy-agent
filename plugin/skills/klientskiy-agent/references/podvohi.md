# Подвохи

| Симптом | Причина | Лечение |
|---|---|---|
| Клиент получает «передайте код владельцу» | политика доступа `pairing` (она по умолчанию) | `dmPolicy: "open"` в `access.json` |
| Агент не стартует на подписке Pro | запрошен Opus, на Pro его нет | пересоздать с `--model sonnet` |
| Бот принимает сообщения, но не отвечает | исходящий гейт не знает политику `open` | обновить канал из `assets/channels` |
| Служба `active`, агент молчит | не поднялся мост до мессенджера | посчитать процессы канала, `systemctl restart` |
| Сессия висит молча после старта | не подтверждено окно загрузки своего канала | автоподтверждение уже в `start-channels.sh` |
| Входящие исчезают бесследно | свой канал указан ещё и в `--channels` | только `--dangerously-load-development-channels` |
| Агент «ответил», человек не получил | текст ушёл в терминал, а не инструментом `reply` | правило в персоне, не перезапуск |
| Бота добавили в группу — молчит | включена приватность бота | `/setprivacy` → Disable и **заново добавить** в группу |
| `409 Conflict` в логе | тот же токен опрашивает кто-то ещё или висит вебхук | один токен — один потребитель |
| Живой токен MAX показывает «мёртв» | `curl` без корня Минцифры: пустой ответ, код 000 | `--cacert ca.pem` |
| «Malformed access token» в MAX | проверяли на старом адресе | `platform-api2.max.ru`, заголовок без Bearer |
| Чужой агент замолчал после установки нового | новый забрал его `bot.pid` | своя папка состояния каждому |
| Бот называет цену, которой нет | строка в `03-цены.md` со статусом «да» | чинить базу, а не персону |
| Деплой ругается на метки | в базе остались `{{…}}` | это защита: без фактов агент выдумывает |

## Правила, которых не видно в коде

- **Бот не может написать первым.** Пока человек не нажал «Начать», он недоступен. Прогрев
  и рассылки ботом не делаются.
- **Личный аккаунт автоматизировать нельзя** — блокируют. Для лички агент читает и готовит
  черновики, отправляет человек.
- **Markdown не разбирается**: звёздочки и решётки человек увидит как есть.
- **У бота нет истории переписки** — только то, что пришло в текущую сессию.
- **Один бизнес — один бот.** Чужого бота не переиспользуют: его база, метки и репутация
  уедут вместе с ним.
- **Instagram — только через агрегатора** с официальным API и только на входящие.
