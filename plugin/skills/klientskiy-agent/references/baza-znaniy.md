# База знаний: семь файлов

Это 80% качества агента и 80% времени работы. Источник — **реальные материалы владелицы и
живая переписка**, а не догадки и не линейка из презентации: она почти всегда расходится
с тем, что реально продаётся.

| Файл | Что внутри | Где взять |
|---|---|---|
| `01-кто-мы.md` | кто мы, чем доказываем, кейсы | даты, лицензии, рейтинги — только проверяемое |
| `02-услуги.md` | что продаётся на этой неделе | прайс и описания |
| `03-цены.md` | цены и колонка «Называть» | прайс + решение владелицы построчно |
| `04-возражения.md` | дорого, подумаю, у других дешевле | **переписка с клиентами** |
| `05-стоп-темы.md` | чего нет и о чём молчим | разговор с владелицей |
| `06-голос.md` | как агент разговаривает | 10–15 живых фраз из переписки |
| `07-воронка.md` | куда ведём и какие контакты даём | решение владелицы |

## Колонка «Называть» — главный приём

У каждой цены стоит разрешение её произносить. Пока «нет» — агент говорит «назову после
короткого разговора» и передаёт человеку. Подтверждает только владелица, правкой файла.

Новая строка всегда заводится со статусом «нет». Цена, не проверенная продажей, — это
гипотеза, и гипотезы живым клиентам не называют.

## Отрицательные факты обязаны быть написаны

«Набора сейчас нет», «это не продаём», «этого не делаем». Если не написать — модель начнёт
продавать по аналогии с тем, что знает про похожие бизнесы. Это самая частая причина, по
которой бот «придумывает».

## Голос

Открыть переписку с клиентами и выписать живые фразы. Этот файл важнее всех рассуждений
о тоне бренда: по нему агент и звучит как владелица, а не как ассистент из интернета.

Отдельно выписать, **как не говорим**: канцелярит и штампы, по которым сразу видно бота.

## Как база живёт дальше

Агент сам ведёт `memory/voprosy-bez-otveta.md` — список того, чего в базе не нашлось.
Раз в неделю его разбирают и закрывают строки. Каждая закрытая строка делает агента умнее,
и это единственный правильный способ его «дообучать».
