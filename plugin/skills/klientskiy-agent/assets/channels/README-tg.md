# Канал Telegram для клиентских ботов (`plugin:tg@__MKT_NAME__`)

Канал для бота, которому пишут **клиенты**. Сделан из нашего канала MAX: доступ, pairing,
обработка входящего, один потребитель на токен, служебный журнал — те же функции из `lib.mjs`,
телеграмное — только слой API и разбор update.

## Зачем он, если есть официальный плагин Anthropic

У официального `telegram@claude-plugins-official` три политики доступа: `pairing` (по умолчанию),
`allowlist`, `disabled`. Для личного помощника это правильно: посторонний не должен попасть в
чужую сессию. Для продающего бота это провал первого касания — человек спрашивает цену и получает:

> Я пока не могу отвечать: мой владелец должен подтвердить доступ. Передайте ему этот код.

Политики «пускать всех» там нет, и дописать её нельзя: плагин лежит в кэше
(`~/.claude/plugins/cache/claude-plugins-official/telegram/`), и первое же обновление молча
вернёт всё назад — бот перестанет отвечать клиентам в самый неудачный момент.

Поэтому здесь есть `dmPolicy: "open"`.

| | официальный telegram | наш tg |
|---|---|---|
| pairing / allowlist / disabled | есть | есть |
| **open — отвечать незнакомым** | нет | **есть** |
| метка источника из `?start=` | есть | есть, приходит как `start_payload` |
| группы | есть | есть |
| авторасшифровка голосовых своей командой | нет | есть |

Личным помощникам менять ничего не нужно: они остаются на официальном плагине.

## Подключение на сервере

1. **Маркетплейс.** Положить обновлённый `claude-plugins-trikita` туда, где лежит текущий, затем:
   ```bash
   claude plugin marketplace update __MKT_NAME__
   claude plugin install tg@__MKT_NAME__
   ```

2. **Папка состояния** — своя на каждого бота:
   ```bash
   mkdir -p /root/.claude/channels/iimpuls-tg && chmod 700 /root/.claude/channels/iimpuls-tg
   cd /root/.claude/channels/iimpuls-tg
   read -s -p "токен от @BotFather: " T; echo; printf 'TELEGRAM_BOT_TOKEN=%s\n' "$T" > .env; chmod 600 .env; unset T
   ```

3. **access.json** — кого пускаем:
   ```json
   {
     "dmPolicy": "open",
     "allowFrom": [],
     "groups": { "-100XXXXXXXXXX": { "requireMention": false } }
   }
   ```
   Файл перечитывается на каждом входящем — рестарт не нужен. Правит его человек в терминале;
   агенту трогать его запрещено (в `settings.json` стоит deny).

4. **Запуск.** Канал передаётся **только** флагом `--dangerously-load-development-channels`:
   ```bash
   export TG_STATE_DIR="/root/.claude/channels/iimpuls-tg"
   # официальный telegram-плагин включён глобально: без своей пустой папки он заберёт чужой bot.pid
   export TELEGRAM_STATE_DIR="/root/.claude/channels/iimpuls-unused"
   CLAUDE_BASE="--permission-mode dontAsk --dangerously-load-development-channels plugin:tg@__MKT_NAME__"
   ```
   ⚠️ Если тот же плагин указать ещё и в `--channels`, Claude Code проверит его по allowlist,
   напишет в MCP-лог «Channel notifications skipped» и **молча выбросит все входящие**.

5. **Права агента** (`.claude/settings.json` рабочей папки):
   ```json
   "allow": ["mcp__plugin_tg_tg__reply", "mcp__plugin_tg_tg__typing"],
   "deny":  ["Read(//root/.claude/channels/**)", "Edit(//root/.claude/channels/**)"]
   ```

## Политики доступа

| `dmPolicy` | Личка | Для кого |
|---|---|---|
| `open` | отвечаем любому, кто написал | **клиентский бот** |
| `pairing` | незнакомцу код для владельца | личный помощник |
| `allowlist` | только `allowFrom`, остальных молча отбрасываем | закрытый бот |
| `disabled` | не отвечаем никому | пауза |

В группах: группа работает, только если её `chat_id` есть в `groups`. Свой `allowFrom` у группы —
слушаем только этих людей. Пусто и `dmPolicy: open` — слышим любого участника (так куратор
отвечает в чате потока). Пусто и `pairing`/`allowlist` — действует общий `allowFrom`, иначе любой
участник группы получил бы доступ к личному агенту.

`requireMention: true` — отвечаем только когда позвали по имени или ответили на сообщение бота.

## Настройки в `.env`

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен от @BotFather, обязателен |
| `TG_POLL_TIMEOUT` | 30 | длина long polling, секунды |
| `TG_TEXT_CHUNK` | 3900 | на сколько режется длинный ответ (предел Telegram — 4096) |
| `TG_TYPING_TIMEOUT_SEC` | 180 | сколько держать «печатает…» |
| `TG_AUTO_DOWNLOAD` | `image,audio` | что скачивать сразу |
| `TG_TRANSCRIBE_CMD` | — | команда расшифровки голосовых, путь к файлу добавляется последним аргументом |
| `TG_TRANSCRIBE_NOTICE` | `Слушаю голосовое…` | что написать человеку, если расшифровка затянулась |
| `TG_DOWNLOAD_MB` | 20 | предел скачивания (у Bot API жёсткие 20 МБ) |
| `TG_SEND_MB` | 50 | предел отправки |
| `TG_API_BASE` | `https://api.telegram.org` | подменяется в тестах |

## Что лежит в папке состояния

```
.env           токен и настройки, права 600
access.json    кого пускаем; правит человек
bot.pid        кто сейчас опрашивает токен
updates.json   offset long polling и последние message_id — без дублей после рестарта
dialogs.json   кто писал боту: в эту личку можно отвечать
inbox/         скачанные вложения и голосовые
channel.log    форма входящих без текста: что пришло и что с ним стало
```

## Тесты

```bash
node test/selftest.mjs     # 33 проверки чистых функций, без сети
node test/e2e-mock.mjs     # 13 сквозных сценариев на поддельном Bot API
```

Сквозной тест поднимает поддельный Telegram на `127.0.0.1`, запускает канал как MCP-сервер и
проверяет главное: незнакомец при `open` доходит до агента и **не** получает код, длинный ответ
режется на части, метка `?start=` доезжает, голосовое скачивается и расшифровывается, в незнакомую
личку бот первым не пишет, в группе из `access.json` слышит любого участника, offset сохраняется.

## Грабли

- **409 Conflict** — токен уже кто-то опрашивает: либо на боте висит вебхук (`deleteWebhook`),
  либо тот же токен слушает другой агент или официальный плагин. Один токен — один потребитель.
- **401 Unauthorized** — токен перевыпустили или бота удалили в @BotFather. Канал об этом пишет
  прямо и ждёт минуту между попытками.
- **Текст в терминале не доходит до человека.** Ответ уходит только инструментом `reply`.
- **Markdown не разбирается**: звёздочки и решётки человек увидит как есть. Пишите простым текстом.
- Вложения качаются по `file_id` и только то, что пришло в эту сессию: истории у бота нет.
