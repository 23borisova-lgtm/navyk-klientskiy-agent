# Клиентский агент в мессенджерах

Навык Claude Code: собрать ИИ-агента, который **отвечает клиентам** в Telegram, MAX и
ВКонтакте — консультирует по базе знаний владельца, не выдумывает цен, доводит до следующего
шага, забирает телефон и передаёт горячего лида человеку.

Собран на опыте живой установки (октябрь 2026) и проверен на сервере: каналы, предохранители
и проверки — те же, что работают в бою.

## Установка

Как плагин (маркетплейс — этот репозиторий):
```
/plugin marketplace add 23borisova-lgtm/navyk-klientskiy-agent
/plugin install klientskiy-agent@klientskiy-agent
```
Или скопировать папку `plugin/skills/klientskiy-agent` в `~/.claude/skills/`.

Репозиторий приватный — командой выше поставит себе только владелец. Чтобы его ставили
ученицы, сделать репозиторий публичным:
```
gh repo edit 23borisova-lgtm/navyk-klientskiy-agent --visibility public
```

Дальше просто попросить Claude: «сделай бота для клиентов» — навык поведёт по шагам.

## Почему каналы лежат внутри

В Claude Code нет готового канала, который пускает **незнакомцев**: у официального
telegram-плагина только `pairing`, `allowlist` и `disabled`, и клиент вместо ответа получает
код для владельца. Поэтому в навык вложены свои каналы `tg` и `max` с политикой `open`.
Без них бот не примет ни одного сообщения.

## Быстрый старт

```bash
python3 plugin/skills/klientskiy-agent/scripts/new_agent.py \
  --slug lingva --biz "Лингва" --owner "Ирина" --city "Пенза" \
  --server root@1.2.3.4 --model sonnet
```

Дальше: заполнить `knowledge/`, завести бота, положить токен на сервер, `bash deploy.sh`,
прогнать двадцать четыре вопроса и живой диалог со второго телефона.
