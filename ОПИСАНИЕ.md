# О чём навык и как им пользоваться

## Подпись — для платформы курса и для чата

> **Клиентский агент в мессенджерах.** Собирает вашего ИИ-администратора, который отвечает
> клиентам в Telegram и MAX: консультирует по вашей базе знаний, не выдумывает цен, доводит
> разговор до следующего шага, забирает телефон и передаёт вам горячего клиента. Мозг — Claude
> на вашей подписке, бот ваш, сервер ваш, данные ваши.

Одной строкой: **ИИ-администратор, который отвечает вашим клиентам и приносит заявки — на
вашей подписке и вашем сервере.**

## Чем отличается от конструктора ботов

Конструктор — это дерево кнопок и «я вас не понял» на любой живой вопрос. Здесь агент читает
сообщение целиком и отвечает по вашим материалам, но строго в границах, которые вы ему
поставили. Границы и есть главная работа:

- у каждой цены стоит **разрешение её называть** — пока его нет, бот говорит «назову после
  короткого разговора» и зовёт человека;
- **чего нет — написано прямо**, иначе модель начнёт продавать по аналогии с похожими
  бизнесами, которые она «знает»;
- деньги, скидки, договор, жалобы — **всегда человек**, бот даже не называет порядок суммы.

## Как пользоваться

**Поставить** — один раз:

```
/plugin marketplace add 23borisova-lgtm/navyk-klientskiy-agent
/plugin install klientskiy-agent@klientskiy-agent
```

Или скопировать папку `plugin/skills/klientskiy-agent` в `~/.claude/skills/`.

**Вызвать** — словами, в обычном разговоре с Claude. Навык поднимается сам: «сделай бота для
клиентов», «хочу, чтобы кто-то отвечал в телеграме вместо администратора», «нужен
ИИ-продажник», «собери базу знаний для бота». Слово «навык» произносить не нужно.

**Что произойдёт дальше.** Claude сначала спросит то, без чего нет смысла начинать: есть ли
подписка и какая (на Pro не работает Opus — частая причина «у меня не завелось»), есть ли
сервер и ключ к нему, есть ли бот, собраны ли материалы. Потом развернёт проект одной
командой, вместе с вами соберёт базу знаний, поможет завести бота и положить токен на сервер,
поднимет службу и прогонит проверки.

**Порядок, который нельзя менять:**

```
база знаний → предохранители → бот и токен → сервер → тест → и только потом живые клиенты
```

Деплой намеренно не выкатит агента, пока в базе остались незаполненные места: агент без фактов
начинает выдумывать, и это хуже, чем его отсутствие.

**Что считается результатом.** Не зелёная служба и не «агент ответил в терминале», а живой
ответ, пришедший в мессенджер с другого телефона, и заявка, которая дошла до владельца.

## Для урока

`plugin/skills/klientskiy-agent/references/urok.md` — письмо ученицам за три дня, блоки урока
с таймингами, домашка с критерием сдачи и таблица «что пойдёт не так» с готовыми ответами.

## Что в комплекте, а чего нет

**Есть:** каналы Telegram и MAX с политикой `open` (бот отвечает незнакомым людям — готового
такого канала в Claude Code нет), персона с девятью предохранителями, семь заготовок базы
знаний, оповещения владельцу, заявка в CRM (АльфаCRM, вебхук или файл), проверки, служба,
первичная установка на чистый сервер, удаление данных клиента по требованию и ежедневная
чистка вложений.

**Нет:** канала ВКонтакте — сообщество можно подготовить заранее, но отвечать бот начнёт
только когда канал появится в навыке. Instagram — только через агрегатора с официальным API,
это отдельные деньги и отдельный разговор.
